# Contact marks

LinkedIn, Instagram, TikTok, X and GitHub SVG paths come from Simple Icons 13.0.0 (https://github.com/simple-icons/simple-icons/tree/13.0.0). Their geometry is unchanged; the fill uses the portfolio cobalt palette. The package license, disclaimer and per-brand source/guideline metadata are included here. Brand rights remain with their owners.

Email and phone are simple interface symbols authored for this portfolio. No account is inferred beyond the supplied email, phone and five social URLs. Contact stamps use these vector marks, never project covers or gallery pictures.
